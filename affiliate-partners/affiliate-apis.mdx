Use these APIs to send Linkrunner traffic from your server instead of through a tracking link. They need no API key: the advertiser's app ID or link domain, plus your campaign code, identify the traffic.

<CardGroup cols={2}>
  <Card title="S2S Click API" icon="server" href="/api-reference/s2s-clicks">
    Report a click from your server when the user goes straight to the store. Accepts AppsFlyer parameter names.
  </Card>
</CardGroup>

For setup steps and how attribution works, start with the guide: [Server-to-Server Clicks](/affiliate-partners/s2s-clicks).
