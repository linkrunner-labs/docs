**A click window is how far back Linkrunner looks for a click when crediting a new install.** If the matching click is older than the window, it is not used, and the install is recorded as organic instead.

This is applied per ad network, so a click from Google Ads and a click from an affiliate can be judged against different windows.

## Default windows

| Ad network | Default click window |
| :--- | :--- |
| Google Ads | 30 days |
| Meta | 30 days |
| Every other network | 7 days |

Google and Meta default to 30 days because installs on those networks often report well after the click. Everything else defaults to 7 days.

These defaults apply automatically. You do not need to set anything to get them.

## Change a window

Go to **Settings → Attribution Windows** in the [dashboard](https://dashboard.linkrunner.io/dashboard/settings/attribution-windows).

The timeline shows each connected channel and its current click-to-install window. Italic values use the Linkrunner default for that channel.

![Attribution Windows settings with connected channels and their click-to-install windows](/images/attribution-windows/attribution-windows-overview.webp)

<Steps>
  <Step title="Choose a channel">
    Click the current day value for a connected channel. To configure another available channel, click **Add channel** and choose it.
  </Step>
  <Step title="Choose the new window">
    Select a value from **1 day** to **30 days**. Linkrunner saves the change automatically for this project.

    ![Click-to-install window selector with values from 1 to 30 days](/images/attribution-windows/change-click-window.webp)
  </Step>
</Steps>

To return a channel to its default, select the italic default value. Changes usually take effect within a minute.

## Limits

Windows can be set from **1 to 30 days**.

The 30 day ceiling is not arbitrary. Linkrunner retains clicks for 30 days, so a click older than that cannot be matched to an install at all, and a longer window would have no effect.

## View-through attribution

**View-through attribution credits an install to a partner's ad impression when there was no click.** A user sees an affiliate partner's ad, doesn't tap it, and installs your app within the view-through window. Linkrunner then credits the install to that impression. Clicks always win: an impression is credited only when no click from any source can be credited.

- **Off by default.** You turn it on for each affiliate partner separately. It applies to partners that report impressions through [S2S impressions](/affiliate-partners/s2s-impressions).
- **1 to 24 hours.** The window starts at **24 hours** when you turn it on. You can shorten it to as little as 1 hour.
- **New installs only.** A change applies to installs from then on. Installs already recorded keep their attribution.

### Turn it on for a partner

<Steps>
  <Step title="Find the partner">
    Go to **Settings → Attribution Windows** in the [dashboard](https://dashboard.linkrunner.io/dashboard/settings/attribution-windows) and find the affiliate partner.
  </Step>
  <Step title="Turn on view-through">
    Turn on **View-through attribution** and select a window from **1 hour** to **24 hours**. Confirm the change.
  </Step>
</Steps>

To stop crediting impressions, turn it off. Linkrunner keeps the window you chose, so turning it back on restores it. Changes usually take effect within a minute.

### What your partner can change

- **Shorten, never extend.** A partner can send a shorter window on each impression with `vt_lookback`. It can never be longer than the window you set. This keeps a partner from claiming your organic installs.
- **Read only.** Partners see your view-through setting in their dashboard but can't change it.
- **Rejected until you turn it on.** Until then, the partner's impressions are rejected with `view_through_disabled`.

<Note>
This matches AppsFlyer, where you turn on view-through and set its lookback window per partner. One difference: in AppsFlyer the partner's `af_viewthrough_lookback` sets the window. In Linkrunner it can only shorten yours.
</Note>

## What this does not cover

The click window governs **click matching only**. It does not change the view-through window above, or probabilistic attribution.

It is also separate from the **Lookback Window** on the Remarketing page. That one controls the reattribution window for users who already have your app. This one controls how a brand new install gets credited.
