Invite `access@linkrunner.io` with **Read only** access. This lets the support team inspect your campaigns and reports without editing campaigns. Google also includes visibility into billing information in this role.

You need **Admin** access to invite someone. If you use a manager account, select the customer account that needs debugging before you start.

## 1. Open access settings

Open [Google Ads](https://ads.google.com/), then go to **Admin → Access and security → Users**. Click the blue **+** button to add a user.

![Google Ads Admin navigation with Access and security, the Users tab, and the blue add-user button](/images/support-access/google-access-navigation.webp)

## 2. Invite Linkrunner

1. Enter `access@linkrunner.io` in **Email**.
2. Select **Read only** under **Select account access level**.
3. Set an **Access expires** date if you want access to end automatically.
4. Click **Send invitation**.

![Google Ads invitation form with access@linkrunner.io and Read only selected](/images/support-access/google-read-only.webp)

## 3. Confirm access

Tell the Linkrunner support team which Google Ads account you shared, including its customer ID. Linkrunner needs to accept the email invitation before access becomes active.

Check **Admin → Access and security → Users** after acceptance. You should see `access@linkrunner.io` with **Read only** access.

## Remove access after support

Return to **Admin → Access and security → Users**, find `access@linkrunner.io`, and select **Remove access**. For an invitation that has not been accepted, use **Revoke** instead.

## Troubleshooting

- **You cannot add a user:** Ask an account administrator to send the invitation.
- **Linkrunner cannot see the affected campaigns:** Check that you shared the correct customer account, especially if you manage multiple accounts.
- **The invitation is still pending:** Confirm the address is `access@linkrunner.io` and notify the support team so they can accept it.

See Google's [access instructions](https://support.google.com/google-ads/answer/6372672) and [access-level comparison](https://support.google.com/google-ads/answer/9978556) for more detail. For Meta, use the [Meta support access guide](/ad-networks/meta-support-access).

**Need help?** Contact [support@linkrunner.io](mailto:support@linkrunner.io).
